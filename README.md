# Gwen-Beauty-Spot-Website
Gwen Beauty Spot Website

Gwen Beauty Spot Website is a responsive e-commerce website developed for a professional makeup artist to establish an online presence and showcase beauty products and services. The website provides customers with an elegant and user-friendly platform to browse products, learn about the business, and connect with the brand.

The project focuses on delivering a modern and visually appealing shopping experience while demonstrating front-end web development skills, responsive design principles, and intuitive user interface design.

Features
💄 Responsive and modern website design
🛍️ Product catalogue showcasing beauty and makeup products
📖 About section introducing the makeup artist and business
📷 Image gallery highlighting products and services
📞 Contact page for customer enquiries
📱 Mobile-friendly and responsive layout
🎨 Professional and elegant user interface
Technologies Used
HTML5
CSS3
JavaScript
Bootstrap
